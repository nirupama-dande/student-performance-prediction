
# Student Performance Prediction using Machine Learning

## Project Overview
This project predicts a student's final grade using machine learning
based on academic, attendance, demographic, and study-related factors.

## Machine Learning Model
- Random Forest Classifier
- Clean Model Accuracy: 87.82%

## Features
- Age
- Gender
- School Type
- Parent Education
- Study Hours
- Attendance Percentage
- Internet Access
- Travel Time
- Extra Activities
- Study Method
- Math Score
- Science Score
- English Score

## Target
Final Grade (A, B, C, D, E, F)

## Result
The trained model successfully predicts the final grade of a student.
